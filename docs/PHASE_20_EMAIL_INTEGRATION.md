## 1. Email Service Provider Selection

**Selected Provider:** **Resend** (Free Developer Tier: 3,000 emails/month, 100 emails/day limit).  
**Fallback / Staging Safe Mode:** Local structured console logging (`ConsoleEmailBackend`) when `RESEND_API_KEY` is not provisioned or during test runs.

---

## 2. Notification Types & Triggering Events

The transactional email engine supports the following core marketplace lifecycle events:

| Email Template | Trigger Condition | Recipient | Actionable Payload |
|---|---|---|---|
| `verification_confirmation` | User registers new account | New User | Verification link with secure token. |
| `password_reset` | User initiates account recovery | User | 15-minute expiring password reset link. |
| `mutual_match_notification` | Bidirectional match established | Both Seekers | Match compatibility score and link to direct chat. |
| `application_received` | Seeker submits rental application | Property Owner | Applicant bio, proposed rent, review button. |
| `application_status_update` | Owner accepts or declines | Applicant | Application status, owner notes, appointment prompt. |
| `appointment_scheduled` | Viewing appointment requested | Host & Seeker | Date, time (IST), property address, calendar invitation (.ics). |
| `safety_alert` | Security policy or warning triggered | Flagged User | Compliance advisory and appeal procedure. |

## 3. Email Authentication & Deliverability Safeguards

To prevent emails from landing in spam folders:
1. **SPF (Sender Policy Framework):** Configured via DNS TXT record (`v=spf1 include:resend.com ~all`).
2. **DKIM (DomainKeys Identified Mail):** 2048-bit cryptographic key rotation managed by Resend.
3. **DMARC (Domain-based Message Authentication, Reporting, and Conformance):** Strict policy (`v=DMARC1; p=quarantine; rua=mailto:dmarc-reports@livora.in`).
4. **Staging Environment Guardrail:** Staging email notifications automatically prefix subject lines with `[STAGING]` and append clear disclaimers that the message was generated by the Flatmate Staging Environment.
