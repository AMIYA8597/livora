# Flatmate Platform API

High-performance, modular FastAPI backend for the Flatmate Compatibility & Rental Marketplace platform.

## Features
- **Deterministic 10-Factor Compatibility Matching Engine**
- **PostGIS Geospatial Proximity Search & Coordinate Fuzzing**
- **Accommodation Inventory Management (Property -> Room -> Bed)**
- **Real-Time WebSockets Messaging & Notifications**
- **Identity & Property Document Verification Pipeline**
- **Supabase Authentication & Row-Level Security Integration**
